# MoneyTrack

A responsive personal finance tracker built with vanilla HTML, CSS, and JavaScript.

## Features

- Starts with a completely empty account
- Dashboard with balance, income, expenses, and savings rate
- Spending by category
- Monthly budgets and progress tracking
- Add, edit, and delete transactions
- Search and filter transactions
- CSV export and import
- Browser localStorage persistence
- Responsive desktop and mobile layout
- Multi-currency support: PHP, USD, GBP, EUR, JPY, CAD, AUD, SGD, HKD, CNY, KRW, and INR
- Light/dark mode with saved preference
- Manual conversion when changing currency
- Clear all saved data
